# Personal skills

My personal agent skills, for sharing between projects.

## Install

Install globally with [skills.sh](https://skills.sh) to use across projects:

```sh
npx skills add soxtoby/skills --global
```

Choose skills and agents when prompted. Omit `--global` to install in the current project.

## Update

Update globally installed skills:

```sh
npx skills update --global
```
